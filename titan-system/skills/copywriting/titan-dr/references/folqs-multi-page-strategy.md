## Strategic Framework: One Product, Multiple Entry Points

Adapted from Primal Viking's "Advertorial Playbook" (245% growth strategy):

- **One product** (FOLQS colostrum) → **multiple landing pages**, each targeting ONE specific pain
- Each page gets its own headline, ad creative, and emotional architecture
- 1:1 ad-to-lander congruence — the ad hook matches the page hook exactly
- Template architecture — Page 1 (Gut/Bloating) is the master template; duplicate structure for each condition
- Every page uses the same Titan DR 10-Reasons listicle format, same compliance shields, same CTA architecture

## Primal Viking Playbook Principles Applied

Source: @funneloftheweek X article analyzing Primal Viking's 245% growth

1. **One Product, Five Angles** → FOLQS: One product, seven angles (pages 1-7)
2. **Template Strategy** → Build one killer listicle, replicate structure per condition
3. **1:1 Ad-Lander Congruence** → Each page has its own ad hooks that match the page hook
4. **Competitive Intercept** → Page 4 (ARMRA) mirrors Primal Viking's "Reindeer vs Beef" play
5. **Story-Based PDP** → Potential future play: story-driven product page with founder narrative
6. **Bencivenga Principles:**
   - Proof Element #4 (Specifics) — exact numbers, not rounded
   - Proof Element #6 (Explain Mechanism) — every reason has a mechanism bridge
   - Proof Element #7 (Sell Against Type) — ARMRA intercept page
   - Proof Element #9 (Highly Believable Source) — study citations, clinical data
   - "No Interest" exit — if they're not interested after the hook, let them go
   - Persuasion Equation — applied in CTA architecture
7. **Schwartz Awareness Targeting** → Each page calibrated to specific awareness level
8. **Dark creative patterns** → Masculine/feminine variants, UGC-style, face-forward imagery
